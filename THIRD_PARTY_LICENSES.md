## Bundled or generated material

### MadGraph5_aMC@NLO generated code

- **Files:** `ula_stein_evt_gen/cross_section/v_jets/model/` and the
  MadGraph-generated portions of
  `ula_stein_evt_gen/cross_section/v_jets/processes/`
- **Version:** MadGraph5_aMC@NLO 3.6.2, as recorded in the generated file
  headers (generation date 2025-03-19)
- **Authors:** The MadGraph5_aMC@NLO Development Team
- **Source:** <https://github.com/mg5amcnlo/mg5amcnlo>
- **License:** Adapted University of Illinois/NCSA Open Source License
- **Use and modifications:** Tree-level Standard Model matrix elements were
  generated by MadGraph, converted to JAX-compatible form using MadJax, and
  modified for numerical stability. Generated-file attribution headers are
  retained.

The required MadGraph notice is reproduced at the end of this file.

### MadJax

- **Files:** JAX conversion and compatibility code in
  `ula_stein_evt_gen/cross_section/v_jets/`, including
  `model/madjax_patch.py`, `model/aloha_methods.py`, `model/wavefunctions.py`,
  and `processes/all_processes_jaxified.py`
- **Version:** 0.0.1 (the upstream package version); the generated files do not
  record a source commit
- **Authors:** Lukas Heinrich and Michael Kagan
- **Source:** <https://github.com/madjax-hep/madjax>
- **License:** Apache Software License, as declared in the upstream package
  metadata; <https://www.apache.org/licenses/LICENSE-2.0>
- **Use and modifications:** Used to generate differentiable JAX matrix-element
  code, with subsequent numerical-stability modifications in this repository.

### NNPDF4.0 parton-distribution grid

- **Files:** `ula_stein_evt_gen/cross_section/lhapdf/NNPDF40_lo_as_01180.dat`
  and `NNPDF40_lo_as_01180.info`
- **Set:** `NNPDF40_lo_as_01180`, LHAPDF set index 331900, DataVersion 1;
  only the central member is bundled
- **Authors:** NNPDF Collaboration, as listed in the bundled `.info` file
- **Reference:** R. D. Ball et al., *The path to proton structure at 1% accuracy*,
  arXiv:2109.02653
- **Source:** <https://lhapdfsets.web.cern.ch/current/>
- **License/terms:** The official LHAPDF set metadata does not declare a
  standalone SPDX license for this grid. It is distributed publicly through
  the official LHAPDF archive and is reproduced here without modification to
  its numerical contents. It is not covered by this repository's MIT License.

### Chili phase-space map

The phase-space implementation in `ula_stein_evt_gen/cross_section/phase_space.py`
was written for this project following the algorithm described by E. Bothmann
et al., *Efficient phase-space generation for hadron collider event simulation*,
arXiv:2302.10449. No Chili source code is redistributed.
